# Required runtime inputs and remaining collection

The live Go snapshot is immutable. The example at ../examples/config_example.xml
is a separately prepared template, not the operator's private config. It uses only
fields implemented by the live source. Database/API secrets must be generated by
the person installing it. The original upstream example remains unchanged.

| Input | Use and current status |

| state/, logs and database contents | Operational/player data; excluded from source publication and collection. |

## Collect for private review

scripts/export_public_inputs.py reads only the seven fixed file names above from
the two documented roots. It refuses symlink inputs, special files, oversized
files, private-key markers and existing output filenames. It records missing
files explicitly. It neither changes a service nor publishes the archive.

Run on the VPS:

```sh
python3 /root/nitro-public-inputs.py --output /root/nitro-public-inputs-review.tar.gz
```

Upload that archive privately for review. Do not upload config.xml or keys.
The helper itself does not prove these input contents are safe or licensed to
publish; that review occurs after collection.
